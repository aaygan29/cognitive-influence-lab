# Subspace Communication in the Hippocampal-Retrosplenial Axis

## Mechanism (from abstract)

Using large-scale (up to 1024-channel) recordings across the full hippocampal-retrosplenial cortex circuit (dentate gyrus, CA3, CA2, CA1, RSC) in behaving mice, the authors apply partial canonical correlation analysis, a linear dimensionality-reduction technique, to identify low-dimensional "communication subspaces" between region pairs while statistically accounting for a third region's influence. These subspaces capture distinct input-output transformations in CA1 that link upstream hippocampal activity (DG, CA3, CA2) to downstream cortical targets (RSC), and subspace membership is constrained by neurons' intrinsic firing properties and anatomical (sublayer) location, consistent across spatial and non-spatial tasks. Reactivation of CA1-CA3 subspaces (but not CA1-RSC subspaces) during post-experience sleep correlates with hippocampal replay, linking a specific subspace to memory consolidation. Already accepted for publication in Nature (published_doi present), indicating this passed a further round of peer review beyond the preprint.

## Provisional relevance

Provisional: touches memoryprint directly because "which specific low-dimensional communication subspace reactivates during consolidation" is precisely the mechanistic granularity an idiographic memory model needs beyond a generic "hippocampus is involved" claim; the CA1-CA3-but-not-CA1-RSC dissociation is a concrete, falsifiable prediction.
Provisional: touches tribe-neuroprint because communication-subspace analysis (partial canonical correlation) is a reusable dimensionality-reduction method applicable to any multi-region decoding pipeline in the instrument, potentially sharper than raw functional connectivity.
Provisional: touches wiring-not-weights because subspace membership is shown to be constrained by anatomical location and intrinsic firing properties (wiring-adjacent, cell-type-level features), not purely by learned weights, a data point for the wiring-vs-weights debate.
Provisional: informs gate G8 (external validity) because the finding holds across both spatial and non-spatial task conditions within the same animals, a within-study generalization check, though cross-species/cross-lab replication remains an open external-validity question for NEUROSPINE to track separately.
Provisional: supports NEUROSPINE aim A1 by supplying a specific, mechanistically dissociated (CA1-CA3 vs CA1-RSC) neural subspace linked to a measurable behavioral/physiological readout (sleep replay), directly the granularity of individual-scale, falsifiable claim A1 needs from MemoryDecoder.
