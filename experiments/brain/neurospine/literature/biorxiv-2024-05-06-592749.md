# Episodic Memory Supports the Acquisition of Structured Task Representations

## Mechanism (from abstract)

The authors argue that generalization to new tasks requires learning task representations that reflect the true similarity structure of the task space, and that episodic memory (EM) is what stabilizes those representations during learning, enabling structured knowledge to accumulate rather than drift. They build a neural network model that infers a task representation to minimize the current task's objective, but which can also retrieve a previously encoded task representation from an episodic-memory store to initialize inference on a new but related task. With EM, the model learns the underlying task structure correctly; without EM, task representations drift and structure learning fails. They further show EM retrieval errors (mistakenly retrieving a similar-but-wrong episode) can themselves support structure learning by promoting activation of similar task representations for perceptually similar inputs, an unexpected beneficial-error mechanism.

## Provisional relevance

Provisional: touches memoryprint directly and centrally because this is a mechanistic, falsifiable computational account of exactly what memoryprint's idiographic memory-behavior coupling needs: a specific claim (EM stabilizes task representations; without it, representations drift) with a built-in ablation (remove EM, show failure) already run in the paper.
Provisional: touches cortex-of-anyone because task-representation stability via episodic retrieval is a candidate mechanism for MemoryDecoder within the personal digital-brain stack, particularly for modeling how a specific individual's past episodes shape their current task representations.
Provisional: touches decision-phenotype because retrieval-based initialization of task representations is relevant to how the AIM-DDM framework should handle transfer across related decision contexts for the same subject.
Provisional: informs gate G6 (mechanism and necessity) strongly because the paper already contains the required intervention: the EM-ablation (no-EM model) that removes the mechanism and shows the effect (structured learning) disappears, precisely the template G6 asks NEUROSPINE projects to run on their own claims.
Provisional: supports NEUROSPINE aim A1 by giving a computational account of how an individual's task representations should be expected to be shaped by their own episodic history, informing what a truly idiographic (not group-averaged) memory model needs to capture.
