# NEUROSPINE Architectural Decision Records (ADRs)

This folder holds architectural decisions using the Michael Nygard ADR format.

## Filename convention

`ADR-<NNN>-<slug>.md` where NNN is a zero-padded number (e.g., ADR-000, ADR-001,
ADR-042) and slug is a kebab-case identifier for the decision topic.

## Template

Every ADR must include:

- **Status**: one of accepted, proposed, superseded, deprecated.
- **Context**: the problem or situation that motivated the decision.
- **Decision**: what was decided, stated in active voice.
- **Consequences**: what changes as a result (positive and negative).

## Conventions

- No em dashes. Recast with periods, commas, colons, or parens.
- Plain ASCII.
- Cross-reference related ADRs, portfolio projects (../portfolio/*/evaluation.md),
  and PRs.
