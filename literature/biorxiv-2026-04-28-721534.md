# A Dataset of Simultaneous Two-Photon Calcium Imaging and Auditory Discrimination Behavior

## Mechanism (from abstract)

The authors release a large-scale, standardized, AI-ready dataset pairing simultaneous two-photon calcium imaging of mouse primary auditory cortex (A1) with detailed behavioral records during an auditory two-alternative forced-choice (2AFC) task (classifying tones as low or high frequency via left/right licking). Data are preprocessed, synchronized, and formatted as trial-aligned multi-dimensional tensors, with validation confirming consistent, high-fidelity temporal dynamics and distinct frequency tuning across conditions. The dataset is benchmarked across multiple machine-learning and deep-learning architectures for neural decoding, explicitly framed as infrastructure for AI-for-neuroscience method development and brain-inspired computational model testing.

## Provisional relevance

Provisional: touches tribe-neuroprint and bio-toolkit because a standardized, benchmarked neural-plus-behavior dataset with pre-established decoding baselines is a direct candidate testbed for validating new decoder components before applying them to NEUROSPINE's primary (presumably human, multimodal) datasets.
Provisional: touches decision-phenotype because a 2AFC discrimination task with trial-aligned neural and behavioral tensors is structurally similar to a minimal decision task, useful as a low-cost sanity-check environment for DecisionDecoder before scaling to more complex human paradigms.
Provisional: informs gate G1 (provenance and leakage) because the dataset's explicit preprocessing/synchronization pipeline and versioning is a template for how NEUROSPINE should document its own data provenance and hashing.
Provisional: informs gate G10 (reproducibility) because the dataset ships with benchmarked baselines across multiple architectures, giving NEUROSPINE a concrete external reference point for a `make reproduce`-style sanity check on any decoder claiming novel gains.
Provisional: supports NEUROSPINE aim A1 only as infrastructure, not as a direct test of individual-scale human thought prediction, since the species (mouse) and cognitive domain (simple auditory discrimination) are far narrower than NEUROSPINE's target claims.
